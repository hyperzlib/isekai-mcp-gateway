1. 打开 ChatGPT Plugins 设置，点击加号 → Add custom MCP server。
2. 填写名称，在 Connection 中选择 OAuth，并粘贴下方的 Server URL。

```text title="Server URL"
{{mcp_url}}
```

3. 选择登录方式为 DCR
4. 点击 Create as a plugin，首次连接时登录本站并确认权限。
5. 安装创建的插件，按照要求登录百科账号
6. 在新对话中输入 @ 选择它即可使用。

[ChatGPT 官方文档 ↗](https://developers.openai.com/api/docs/guides/custom-mcp-server)
