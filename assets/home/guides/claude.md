1. 打开 Settings → Connectors → Add custom connector。
2. 填写名称，并粘贴下方的 Remote MCP server URL，保存。
3. 首次连接时在浏览器中登录本站并确认权限。
4. 在对话中启用该连接器，然后就可以使用 Wiki 了。

```text title="Remote MCP server URL"
{{mcp_url}}
```
