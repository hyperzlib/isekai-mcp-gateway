Resolve current original file URLs for 1–500 file titles supplied in titles, e.g. {"titles":["文件:示例.png","File:Example.pdf"]}. Accepts File:, Image: and Chinese file namespace aliases. Returns file_urls keyed by 文件: plus each referenced file name. Normalization and redirects are resolved; duplicate names are merged and files without an available URL are omitted. Each call checks wiki:read authorization. Read wiki.help(reading).
