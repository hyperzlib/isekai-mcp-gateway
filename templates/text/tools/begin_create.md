Open a create draft for a new page and return edit_id, version and expires_at. Use this tool to create the edit draft as the first step of writing a new page; it fails if the page already exists, including a pending revision. Pass the returned version as base_version in later calls. Requires wiki:create. Then fill the draft with update_edit and submit with commit_edit. Read wiki.help(editing).
Results include url, the page access address returned by MediaWiki. It is empty until the page has a public page ID. A new workspace starts with url="".
