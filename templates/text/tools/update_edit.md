Atomically apply an ordered batch of operations to the draft; the whole batch is discarded if any step fails. Requires an open edit session from wiki.begin_edit or wiki.begin_create and the latest base_version. Operations: replace_content, replace_text, replace_lines, insert_lines, delete_lines, apply_patch. replace_text must match exactly once; line numbers are 1-based and refer to the result of earlier operations. Read wiki.help(editing) and wiki.help(patch).
