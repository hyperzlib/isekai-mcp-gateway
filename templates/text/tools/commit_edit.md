Submit the current draft. Requires an open edit session from wiki.begin_edit or wiki.begin_create, base_version, summary and ai_involvement (none, ai_organized, ai_assisted or ai_generated). If a confirmation challenge is returned, confirm it in a separate call with challenge_responses. outcome=saved or nochange returns a new version and keeps the session; outcome=submitted_for_review closes it. After a network error read get_edit_status and pull_edit before retrying. Read wiki.help(editing) and wiki.help(moderation).
Results include url, the page access address returned by MediaWiki. It is empty until the page has a public page ID. Successful submissions (including nochange) refresh url. url_refresh_warning means URL refresh failed after the submission was accepted; do not resubmit. Use pull_edit for an open session.
