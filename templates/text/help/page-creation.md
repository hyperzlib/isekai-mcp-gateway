# 新建页面

创建百科页面时，请先确定你的世界观名字，然后按照下面规则命名。这样可以让读者更容易找到相关内容。

## 1. 世界观介绍页面

第一步：先创建世界观的介绍页面。
即使你只想先发布人物设定、剧情设定，也需要先创建世界观根页面。

命名建议：
避免仅使用过于通用的词语作为标题，比如 `赛博朋克`、`奇幻`。
推荐格式：`XXX的世界`（例：`异晶危机的世界`）
不要在标题里直接加副标题；如果需要副标题，可以在页面编辑器的设置中设置显示标题。

## 2. 子设定页面（人物、剧情等）

命名格式：
`世界观页面名/设定名`
或 `世界观页面名/人设/人物名`
这样命名可以让百科自动建立“子设定 → 世界观设定”的关联。
建议不要超过四级层级。

## 3. 分类页面

分类命名格式：
`分类:世界观页面名`
或 `分类:世界观页面名/设定类型`
注意使用 英文冒号（:）而不是中文冒号。
分类页面一般会在子页面创建后自动创建，除非分类下有大量页面，且你打算增加一些对于这些页面的介绍，否则无需单独建立分类页面。

## 命名示例

`灵能世界`
`灰烬世界观`
`异晶危机的世界`
`异晶危机的世界/人物/白神成太`
`代号:曙光的世界/黄昏的阿瓦隆`
