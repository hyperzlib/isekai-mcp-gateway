# wikitext 语法

页面正文使用 wikitext 编写，提交前用 preview_edit 检查渲染结果。Markdown 记号（## 、** 、`>` 等）不是 wikitext，转换现有文档时逐项替换为对应语法。

## 标题

标题用等号包围，数量表示层级：`= 一级 =`、`== 二级 ==`、`=== 三级 ===`，层级递进不跳级。目录按标题自动生成；页面已有页面名时，正文一般从二级开始，站点模板示例中若使用一级标题则照模板写。

## 段落与排版

空行分段；单个换行只显示为空格，强制换行使用 `<br>`。文字样式：`''斜体''`、`'''粗体'''`、`'''''粗斜体'''''`，上下标使用 `<sub>`、`<sup>`。

## 列表与缩进

`*` 无序列表、`#` 有序列表，`**`、`##` 嵌套一层；连续行组成同一列表。`:` 开头的行产生缩进段落。

## 链接

内部链接 `[[页面名]]`，显示自定义文字用 `[[页面名|显示文字]]`；目标不存在时显示为红链，可正常保存。外部链接写 `https://example.com` 或 `[https://example.com/ 显示文字]`。

## 文件与分类

嵌入文件写 `[[文件:名称.jpg|无框|左|说明]]`，选项顺序灵活；文件上传见 wiki.help(uploads)。分类标签 `[[分类:人设]]` 建议放在页面末尾，同一页面可有多个分类。

## 表格与原样显示

表格以 `{|` 开始、`|}` 结束，单元格用 `|` 或 `||`（不熟悉时避免手写复杂表格）。需要原样显示 {{"{{"}}模板}}、`[[链接]]` 等 wikitext 时，用 `<nowiki>` 包围被解析的片段。

## 禁用项

`<style>`、`<script>` 不可用，也不要用 HTML 堆整页版式；样式表达交给站点模板。
