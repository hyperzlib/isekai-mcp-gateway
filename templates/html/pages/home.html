添加 MCP 服务器

Cherry Studio

  1. 打开 设置 → MCP 服务器 → 添加。
  2. 类型选择 Streamable HTTP，填入下方的服务器 URL，保存并开启开关。
  3. 首次连接时会打开浏览器要求登录本站并确认权限，登录一次即可。
  4. 在对话的工具面板中确认已启用本服务器，然后就可以直接让 AI 使用了。

OpenCode

  1. 把下方的配置合并到 opencode.json 中。
  2. 运行授权命令，在浏览器中登录本站并确认权限。
  3. 回到 OpenCode，把 Wiki 相关任务交给它即可。
opencode.json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "isekai": {
      "enabled": true,
      "type": "remote",
      "url": {{.EndpointJSON}}
    }
  }
}
授权与检查
opencode mcp auth isekai
opencode mcp list

常见问题

已连接，但没有出现工具？

检查服务器是否启用、当前助手或 Agent 是否绑定了它，以及模型是否支持工具调用。刷新工具列表后发送新消息。

需要重新授权怎么办？

在客户端的 MCP 设置中重新连接或登录，完成浏览器授权。若已取消授权，需要再次同意所需权限。

为什么提示权限不足？

当前授权可能只允许阅读。需要编辑或其他操作时，重新授权并选择所需权限。

通过 MCP 连接 · 客户端界面可能随版本更新，若页面与实际不符请参考各客户端官方文档。
